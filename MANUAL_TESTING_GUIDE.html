Scenario D — Underage Patient (Under 18 years) UNDERAGE MODE
Steps
  1. Open Register Patient page
  2. In Date of Birth, select any date less than 18 years ago (e.g. 2015-03-10)
  3. Verify that the form changes — Guardian and Relationship fields appear
  4. Verify NIC, Address, Mobile, Email fields become disabled/locked
  5. Try to submit without selecting a Guardian → check error
  6. Try to submit without selecting Relationship to Guardian → check error
  7. Click the Guardian field → Guardian Search Dialog opens → search and select a guardian
  8. Verify guardian's contact details auto-fill into NIC, Address, Mobile, Email fields
  9. Select Relationship to Guardian (e.g. Mother) → submit with all other valid fields
What to CheckExpected Result
DOB set to child's age (e.g. 2015)Guardian + Relationship fields appear dynamically
NIC fieldDisabled / grayed out (not editable)
Address, City, District fieldsDisabled / grayed out
